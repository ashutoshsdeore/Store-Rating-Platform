# Store Rating Platform

## Features

### Admin
- Manage Users
- Manage Stores
- Dashboard Statistics
- User Details View
- Filters & Sorting

### User
- Register/Login
- Search Stores
- Submit & Update Ratings
- Change Password

### Store Owner
- View Average Rating
- View Users Who Rated
- Change Password

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js

Database:
- MySQL

Authentication:
- JWT
- bcryptjs
